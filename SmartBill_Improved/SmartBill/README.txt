SMARTBILL - IMPROVED MULTI-PAGE WEBSITE

FILES
- index.html      : Home / Dashboard
- products.html   : Product Management
- bill.html       : Create Bill form
- customers.html  : Customer Management
- history.html    : Bill History
- style.css       : Shared design for all pages

HOW TO RUN
1. Keep all six HTML/CSS files in the same folder.
2. Open the folder in VS Code.
3. Open index.html in a browser.
4. Use the navigation bar to move between pages.

IMPORTANT
This project uses HTML and CSS only. The bill form is a front-end demo.
Automatic calculations, saving bills, and updating tables need JavaScript
or a backend, which are not included in this version.
